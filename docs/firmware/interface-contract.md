# 接口契约冻结模板（v0.1 草案，未审批）

> 这只是初始草案。进入 USB 与输入模块并行实现前，必须经主 Agent 审核并写入最终签署版本。任何变更由主 Agent 提交 ADR，并同步更新描述符与测试。

## 核心状态（示例）
```c
#include <stdint.h>
typedef struct {
    int16_t lx, ly, rx, ry;  /* 中心 0，范围另行冻结 */
    uint8_t lt, rt;          /* 0..255, 0 代表未按下 */
    uint16_t buttons;        /* 数字按键位映射另行冻结 */
    uint8_t hat;             /* 0..7, 8 neutral */
    uint32_t sample_ms;
} gamepad_state_t;
```

## 必须冻结的字段
- C 类型、每个轴的逻辑最小/最大值、方向与中心值
- 键值 bit 索引、Start/Select/Home 含义；D-pad 使用 hat 还是四个独立按键，不能双重计数
- HID Report ID（如果采用）、传输字节顺序、报文确切长度、对齐和填充
- USB 轮询间隔与报告频率目标；API 可调用任务/上下文
- 样本快照同步方式；同一帧不得混合不同采样周期的按钮和摇杆
- USB 未挂载、挂起、恢复与断开时的中立态处理
- 校准参数版本与默认值、NVS 字段迁移与异常恢复
- 设备识别标识：开发测试使用合法适用的测试 VID/PID；量产必须有合法授权 VID/PID
