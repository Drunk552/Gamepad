## 1. 核心状态 gamepad_state_t

```c
#include <stdint.h>

typedef struct {
    int16_t lx, ly, rx, ry;  /* 摇杆轴，中心 0，范围 -32768..32767，方向见 §5 */
    uint8_t lt, rt;          /* 扳机，0..255，0 = 未按下 */
    uint16_t buttons;        /* 位映射见 §3，bit11..15 保留恒 0 */
    uint8_t hat;             /* 0..7 方向，8 = 中性，见 §4 */
    uint32_t sample_ms;      /* 本帧采样时间戳（毫秒）*/
} gamepad_state_t;
```

- 唯一写者：`gamepad_core` 内的输入任务（500 Hz 采样）；`usb_gamepad` 只读消费（§6）。
- 公共头文件必须注明：生产者/消费者 API 均只允许任务上下文调用，不得在中断中调用（ADC 驱动内部采集除外）。

## 2. HID 报告（13 字节，冻结）

D1：M0 即采用**全量报告**，未实现的输入恒发中性值，M0→M1 不改描述符。

| 偏移 | 长度 | 字段 | HID Usage | 逻辑范围 | 中性值 |
|---|---|---|---|---|---|
| 0 | 2 | LX | X | -32768..32767 | 0 |
| 2 | 2 | LY | Y | -32768..32767 | 0 |
| 4 | 2 | RX | Rx | -32768..32767 | 0 |
| 6 | 2 | RY | Ry | -32768..32767 | 0 |
| 8 | 1 | LT | Z | 0..255 | 0 |
| 9 | 1 | RT | Rz | 0..255 | 0 |
| 10 | 1 | hat | Hat switch | 0..7（Null State） | 8 (0x08) |
| 11 | 2 | buttons | Button 1..16 | 位域 | 0 |

- 不使用 Report ID（D4：单报告设备）。
- 多字节字段小端（HID 位域默认 LSB 先行）。
- 字节对齐、无跨字节位域；hat 字节高 4 位恒 0。
- 报告总长 13 字节，必须与 HID Report Descriptor 生成物逐字段一致（T-USB-01/M0-03 审计点）。

## 3. 按钮位映射（D3：Xbox 序）

| bit | 按钮 | 说明 |
|---|---|---|
| 0 | A | |
| 1 | B | |
| 2 | X | |
| 3 | Y | |
| 4 | LB | |
| 5 | RB | |
| 6 | Select | |
| 7 | Start | |
| 8 | L3 | 左摇杆按压 |
| 9 | R3 | 右摇杆按压 |
| 10 | Home | |
| 11..15 | 保留 | 恒 0 |

- **D-pad 只经 hat 传输**，不占按钮位、不双重计数（15 数字键中 4 个方向键走 hat，按钮位实际使用 bit0..bit10 共 11 个）。
- C 位序与线上格式一致：bit0 = 报告字节 11 的最低位。

## 4. hat 编码（D6）

0=上、1=右上、2=右、3=右下、4=下、5=左下、6=左、7=左上；**中性 = 8**（描述符置 Null State 标志，线上字节 0x08）。

## 5. 轴方向（D2）

- X / Rx：右为正。
- Y / Ry：**下为正、上为负**（HID 通用桌面惯例，与 Steam/游戏默认一致）。
- 校准只映射零点与满量程，不得改变符号约定。

## 6. 快照同步

- `gamepad_core` 拥有状态并保证线程一致性；transport 只消费不可变快照副本。
- 实现：portMUX 临界区内整结构复制（约 20 字节），禁止向 transport 传递可变指针。
- 同一报告内的轴/按钮/hat 必须来自**同一采样帧**（T-FW-01 判据）；`sample_ms` 随帧一起原子复制。

## 7. USB 状态机与中性态

状态流：`BOOT → INIT → USB_WAIT → USB_ACTIVE`。

- 状态机归属 `gamepad_core`；`usb_gamepad` 只上报 TinyUSB 挂载/挂起/断开事件，不得反向调用输入模块。
- USB_WAIT：不发送报告，内部状态保持中性。
- USB_ACTIVE：按 bInterval 周期发送当前快照。
- 挂起（suspend）：停止周期发送，状态回中性（防卡键）。
- 断开/卸载：退回 USB_WAIT，清空 `gamepad_state_t` 为全中性（lx..ry=0，lt/rt=0，buttons=0，hat=8）。
- 中性帧定义：§2 表中各字段中性值。

## 8. 频率目标（M2 实测校准，非 M0 门槛）

- 输入采样 500 Hz（2 ms）；USB bInterval = 4 ms（250 Hz）。
- 输入变化→报告构建 P99 ≤ 20 ms（requirements 性能目标）。

## 9. 校准与滤波默认值（M0 常量版）

- M0：编译期常量——死区为中心 ±5%（±1638/32767），按键消抖 15 ms，输出限幅到逻辑范围。
- 完整校准（每路独立零点/满量程、NVS 持久化、异常回退出厂值）属 M2，届时以 ADR 升级本节并引入参数版本号（自 v1 起）。

## 10. 设备标识

- 开发期：沿用 esp_tinyusb 示例自带测试 VID/PID 与示例字符串（ADR-0001 #5）；量产前必须替换为授权标识，违反即阻断合并。
