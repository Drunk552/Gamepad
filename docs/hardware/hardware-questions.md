# 需要用户提供的硬件事实（未确认即禁止定板）

1. ESP32-S3 开发板准确型号、开发板正反面照片、原理图或购买链接。
2. 模组 N8/N16、PSRAM 容量；实际可用 IO、原理图复用与 strapping 约束。
3. 板载 USB-C 是原生 USB-OTG 口还是 USB-UART 下载口；USB D-/D+ 与 GPIO19/20 实物连通性。
4. 独立 UART 调试途径；USB HID 工作时能否保留日志。
5. 摇杆模块的实际型号、VCC、输出范围、中心值和阻抗；左右摇杆是否带 L3/R3 按压。
6. LT/RT 模拟扳机的真实元件（霍尔/电位器）和输出方式。
7. 15 个数字输入采用 GPIO 直连、矩阵还是 MCP23017；电平与上拉规划。
8. Windows 版本、Steam 版本、《双影奇境》购买与启动途径、是否支持 Steam Input 映射及最终双人模式。
9. 用户实际焊接工具与可用万用表；初版面包板接线可行性。

没有以上信息时可以推进不依赖硬件的 Host 测试和 USB 描述符设计，不能把 GPIO 选择写为已验证或断言实机成功。
